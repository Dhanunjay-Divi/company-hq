# UI reference catalog

This is a short research catalog, not an adoption or installation plan. Research date: 2026-09-21. It complements [UI reuse decisions](UI-REUSE-DECISIONS.md), which records the retained Munder Difflin office renderer, Agent Teams AI graph, and the on-demand Ponytail and UI/UX Pro Max skills. Candidate inventory and broader upstream disposition remain in [repository-candidates.json](repository-candidates.json) and [UPSTREAM-REVIEW.md](UPSTREAM-REVIEW.md); they are not repeated here.

**Current HQ state (user supplied):** the Office uses original CSS/SVG and MIT-licensed upstream Munder Difflin procedural characters; the Agent Teams graph remains. Ponytail and UI/UX Pro Max are installed as on-demand MIT skills, without hooks or full-plugin activation. This research installed no animation libraries.

## Recommendations

The current Office and Team map remain the implementation baseline. For a future narrowly scoped UI change, first use the installed on-demand skills recorded in [UI reuse decisions](UI-REUSE-DECISIONS.md) to review motion, focus, contrast and small-screen behavior. Use the references above as design evidence only until the exact source, license, dependencies and compatibility are reviewed.

Proposals above are intentionally not sourced product facts: they are HQ-specific recommendations based on the documented offerings and current project constraints. The public-page review did not install packages, open accounts, request pricing, call provider APIs, or benchmark performance.
